# pet-shop-store



## Project Description
Pet Shop Store is a web application designed for managing a pet store.  
The project is developed as part of the **Web Programming** course at IBU.  
It is a responsive website built using **HTML, CSS, Bootstrap, and JavaScript**.  
Future milestones will include adding backend logic, API integration, and SPA functionality.
